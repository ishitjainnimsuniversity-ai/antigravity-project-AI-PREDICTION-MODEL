A professional-grade, deep learning-powered medical analysis suite that provides real-time facial and retinal scanning with advanced 10-year holistic health projections.

## 🚀 Key Features

- **Quantum-Class Neural Architecture**: Powered by a transfer-learning optimized **MobileNetV2** base for high-precision skin classification.
- **Stable Vision HUD**: Real-time OpenCV & Cascade-based retinal tracking with distance guidance to ensure clinical-grade captures.
- **10-Year Evolution Projections**: Dynamic aging-simulation engine that calculates bio-stability scores based on current diagnostics and patient metadata.
- **Automated Clinical Reporting**: Generates a futuristic, encrypted **Sci-Fi Clinical PDF** containing prescription data, dietary plans, and vision maintenance protocols.
- **Comprehensive Dermal Analysis**: Classifies five major conditions: **Acne, Eczema, Psoriasis, Wrinkles, and Healthy Skin.**

## 🛠️ Technology Stack

- **Core**: Python 3.x
- **Deep Learning**: TensorFlow / Keras (MobileNetV2)
- **Computer Vision**: OpenCV (Haar Cascades for Stable Tracking)
- **Data Analysis**: NumPy, Matplotlib
- **Reporting**: FPDF2 (Cyber-clinical PDF Engine)
- **UI**: Matplotlib Interactive Dashboard

## 📦 Installation & Setup

Ensure you have the required medical-grade libraries installed:

```bash
pip install tensorflow numpy matplotlib pillow opencv-python fpdf2
```

## 🖥️ Usage

Launch the Unified Diagnostic Suite:

```bash
python advanced_app.py
```

### Modes Breakdown
1. **Camera Scanner**: Real-time HUD lock-on for dermal and ocular analysis.
2. **Uploading Photo**: Analyzes existing bio-samples (JPG/PNG).

### Capture Keys
- **'S'**: Triggers the **Bio-Capture** process and generates the Unified Dashboard + PDF Report.
- **'Q'**: Safely terminates the scanner.
